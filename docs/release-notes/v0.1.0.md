Orbe 0.1.0, el motor de videojuegos de Nodalia: primera versión, con el editor en el Nodalia Design Language y paquetes para Linux, macOS y Windows.

*Orbe 0.1.0, Nodalia's game engine: the first release, with the editor drawn in the Nodalia Design Language and packages for Linux, macOS and Windows.*

## Español

### Qué incluye

- Motor y editor de videojuegos 2D y 3D con escenas y nodos, lenguaje de scripting, físicas, renderizado y exportación, bajo licencia MIT.
- Un editor con el aspecto de Nodalia: temas oscuro y claro con el acento ámbar de Orbe, esquinas más redondeadas y un menú de hamburguesa con Configuración del editor, Atajos de teclado y Acerca de.
- En Linux, la ventana usa los controles redondos de Nodalia (en los ajustes del editor se pueden cambiar por los del escritorio) y los menús del editor se exportan a la barra superior del escritorio por D-Bus. En macOS y Windows se usan siempre los controles nativos.
- Interfaz completa en español, y los proyectos, escenas y scripts 4.x existentes se abren sin convertirlos.
- Paquetes para Linux (AppImage, .deb, .rpm y .tar.gz), macOS (un DMG universal con su propia ventana de instalación) y Windows (instalador MSI por usuario y zip portable para x64, x86 y arm64).

### Notas

- Los instaladores no están firmados: Windows SmartScreen y macOS avisan la primera vez («Más información» y «Ejecutar de todos modos» en Windows; clic derecho y Abrir en macOS).
- En Windows el motor usa Vulkan y OpenGL; Direct3D 12 no está incluido en esta versión. En Mac con procesador Intel se usa el renderizador de compatibilidad.
- Los paquetes de Windows y macOS se han comprobado solo en la integración continua.

## English

### What's in it

- A 2D and 3D game engine and editor with scenes and nodes, a scripting language, physics, rendering and export, under the MIT licence.
- An editor that looks like Nodalia: dark and light themes with Orbe's amber accent, rounder corners and a hamburger menu with Editor Settings, Keyboard Shortcuts and About.
- On Linux the window uses Nodalia's round controls (an editor setting switches them to the desktop's own) and the editor's menus are exported to the desktop's top bar over D-Bus. macOS and Windows always keep their native controls.
- The whole interface is translated to Spanish, and existing 4.x projects, scenes and scripts open without conversion.
- Packages for Linux (AppImage, .deb, .rpm and .tar.gz), macOS (a universal DMG with its own install window) and Windows (a per-user MSI installer and a portable zip for x64, x86 and arm64).

### Notes

- The installers are not signed: Windows SmartScreen and macOS warn the first time ("More info" then "Run anyway" on Windows; right-click then Open on macOS).
- On Windows the engine uses Vulkan and OpenGL; Direct3D 12 is not part of this version. On Intel Macs the Compatibility renderer is used.
- The Windows and macOS packages have been checked on continuous integration only.
